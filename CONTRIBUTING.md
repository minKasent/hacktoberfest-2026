# Contributing to Hacktoberfest 2026 Algorithms & Architecture Showcase

Thank you for your interest in contributing! This project celebrates open source collaboration during Hacktoberfest 2026.

## 📋 Guidelines for Qualifying Pull Requests

To ensure high engineering standards and compliance with Hacktoberfest quality criteria:

1. **Architecture & Clean Code**: Follow SOLID principles and Clean Architecture idioms.
2. **Type Safety**: Strictly typed TypeScript without `any` overrides.
3. **Complexity Documentation**: Document asymptotic time and space complexity ($O(N)$) in JSDoc headers.
4. **Validation**: All PRs must have accompanying test suites or execution assertions.

## 🏷️ Labels & Review Workflow

- When a pull request meets the technical criteria, maintainers will assign the `hacktoberfest-accepted` label.
- Merged pull requests count directly toward your Hacktoberfest 2026 completion metrics and Holopin badges.
